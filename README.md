# weapp-to-academic-affairs-system
以微信小程序实现的湖南强智教务系统的快捷平台基于vant+cloudbase的轻量化校园服务小程序
-----------------------------------------------------------------------------------------
本平台的功能有学生日常使用的签到打卡，课表查询，论坛交流，二手交易等功能
适用于湖南强智教务系统。
------------------------------------------------------------------------------------
1.微信开发者工具
2.npm
3.vant
----------------------------------------------------------------------------------------
app.js
里面配好云服务器，也需要在上方云开发处创建，填入自己的env
classtable/index.js
填写学校的教务系统网址，需要是湖南强智教务系统
还有课表的list处
club页面和forum页面有隐藏的修改按钮，可以跳转到修改图片页面，不用的时候可以隐藏。
需要自行更改用户协议主体。
论坛有言论审核系统，可以在云开发处云安全添加确认。
课表首次使用需要设置当前周数。后续会有缓存。
登录是仅作本校教务系统登录认证即学生身份认证且无留存
----------------------------------------------------------------------------------------
有更多功能可以挖掘。
